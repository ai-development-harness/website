Документация Harness

Команды Harness

Стабильный человеко-машинный интерфейс: короткие команды запускают предсказуемые процессы на уровне репозитория и оставляют сохраняемые артефакты.

Инициализация и планирование

INIT PROJECT

Однократная инициализация из PROJECT_BRIEF.local.md. Создаёт базу знаний проекта и начальную дорожную карту, но не код продукта.

ADD STEP: <описание>

Преобразует человеческую задачу в новый STEP с границами, зависимостями, критериями приёмки и проверками.

PLAN STEP-NNN

Проводит анализ до реализации и сохраняет Implementation plan внутрь файла задачи.

NEXT STEP

Без изменений рекомендует следующий незаблокированный STEP с учётом зависимостей, приоритета, риска и дорожной карты.

STATUS PROJECT

Проверяет представления состояния, блокирующие проблемы, доступную работу и признаки рассинхронизации.

Выполнение и контроль

IMPLEMENT STEP-NNN

Реализует сохранённый план в пределах контракта задачи и запускает предусмотренные проверки.

REVIEW STEP-NNN

Независимо проверяет задачу, реализацию и доказательства выполнения; создаёт неизменяемый отчёт ревью.

FIX STEP-NNN

Исправляет подтверждённые замечания последнего применимого FAIL-review.

RUN STEP-NNN

Оркестрирует PLAN → IMPLEMENT → проверки → REVIEW → FIX/REVIEW → CLOSE.

AUDIT STEP-NNN

Без изменений проверяет фактическое состояние; найденные дефекты превращаются в замечания или корректирующие задачи.

RECONCILE PROJECT

Ищет расхождения между кодом, тестами и конфигурацией и REQ/ADR/архитектурой/STEP/доказательствами выполнения.

RELEASE CHECK

Проверяет условия выпуска: замечания, требования, миграции, тесты и сборку, безопасность, документацию и вопросы развёртывания.

Мелкие изменения

QUICK FIX: <описание>

Небольшая правка с низким риском без искусственного REQ/ADR/STEP. Если меняется контракт или уровень риска, команда останавливается и предлагает ADD STEP.

Навыки и шаблоны GitHub

FIND SKILL: <описание>

Ищет и проверяет навыки репозитория, сохраняет TOP-5 и ничего не устанавливает.

INSTALL SKILL: <source | #N>

Повторно проверяет выбранный навык и устанавливает его с фиксацией происхождения, реестра и маршрутизации.

CREATE SKILL: <описание>

Создаёт собственный навык проекта, если подходящего готового варианта нет.

GENERATE GITHUB TEMPLATES

Перегенерирует управляемые Issue Forms и шаблон PR по фактическому набору инструментов проекта.

Обновление Harness

CHECK HARNESS UPDATE

Без изменений сравнивает BASE/OURS/THEIRS для разрешённых путей Harness и показывает блокирующие проблемы.

UPDATE HARNESS

После успешной проверки обновляет служебный слой Harness по правилам владения файлами; не создаёт STEP и не выполняет commit/push/PR.

Операции Git

GIT CHECK

Предварительная проверка без изменений: ветка, upstream, diff, целостность, правила проекта и подозрительные файлы.

COMMIT / COMMIT: <подсказка>

Создаёт только локальный безопасный Conventional Commit по git-policy.

PUSH

Публикует текущую ветку без force после проверки расхождения и безопасности.

PR

Создаёт Pull Request или возвращает существующий согласно правилам проекта.

SYNC

Выполняет fetch и показывает ahead/behind; по умолчанию ничего не меняет, опционально допускает только безопасный fast-forward.
